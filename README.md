# LabSense 本地教学版

LabSense 面向医学检验本科生，用固定模拟数据完成“数据检查—缺失值实验—特征工程—相关性与 LASSO—模型比较—SHAP—PCA 与聚类”的完整课堂实验。应用只监听 `127.0.0.1`，不需要 GPT 登录，不上传数据，也不调用外部服务。

## Windows 启动

1. 首次使用双击 `setup.bat`，创建项目专用 `.venv` 并安装固定版本依赖。
2. 以后双击 `start.bat`，浏览器会自动打开 `http://127.0.0.1:8765`。
3. 关闭命令窗口即可停止服务。依赖安装完成后可断网授课。

要求 Python 3.9 或更高版本。推荐投屏分辨率为 1280 × 720 或更高。

## 十个教学环节

1. **研究任务**：用入院血常规与入院诊断提示地中海贫血风险，并明确出院诊断金标准。
2. **查看原始数据**：查看真实读取的前 20 行，不预先泄露数据问题。
3. **数据有哪些问题**：真实扫描单位、年龄、编码、重复、危急值、隐私和缺失问题，并用图表展示证据。
4. **数据处理**：七道标准答案题逐项处理，答对后自动进入下一题。
5. **缺失值实验**：在训练折内比较完整病例删除、中位数与 KNN 填补，并查看填补前后分布。
6. **特征工程**：总览常用方法；演示类别编码、Z 标准化和右偏铁蛋白的 `log(1+x)` 转换。
7. **特征筛选**：相关性热图后运行标准 LASSO 系数路径、五折误差曲线和 1-SE 规则；外层五折评价、内层五折选 λ。
8. **模型比较**：同一患者级五折比较逻辑回归、未剪枝决策树和随机森林的完整/筛选后特征结果。
9. **SHAP 解释**：用真实全局重要性、蜂群图和单患者瀑布图解释实际胜出的模型。
10. **PCA 与聚类**：隐藏金标准后比较 k=2–5，再揭示出院诊断作事后对照。

HGB `<40 g/L` 不会被系统自动删除或判定为错误。教师只能选择核验后保留，或暂不纳入本次分析并等待资料确认。原始 CSV 始终不变。

## 数据与模型原则

- `data/cbc_teaching_raw.csv` 包含 400 名模拟患者和 8 条完全重复记录，随机种子固定为 `20260921`。
- `data/generation_manifest.json` 记录生成参数和异常注入位置。
- 出院诊断和金标准仅用于训练与验证，绝不进入预测输入；入院诊断可在训练折内展开为多标签 0/1 特征。
- 血清铁蛋白按固定机制生成右偏分布。逻辑回归和 LASSO 使用 `log(1+x)` 铁蛋白与 Z 标准化，树模型使用原始铁蛋白。
- LASSO 在每个外层训练折内部重新完成填补、相关性预筛、标准化和五折选 λ，避免验证数据泄漏。
- PCA 用于二维观察，不进入最终监督模型。
- SHAP 解释模型输出，不代表疾病因果机制。
